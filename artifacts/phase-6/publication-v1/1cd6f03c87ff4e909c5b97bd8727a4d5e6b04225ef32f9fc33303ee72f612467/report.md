# Frozen Historical Arena Preference Report

<!-- publication-section:overview -->
## 1. Overview

This report presents estimated preference under the frozen historical Arena population.

<!-- publication-section:research-question -->
## 2. Research Question

The question is how model preferences are estimated in that frozen population, with frozen uncertainty and rank robustness.

<!-- publication-section:data-population -->
## 3. Data & Frozen Population

The source and population are historical and frozen; this report is not a current system comparison.

<!-- publication-section:method -->
## 4. Method

The report consumes accepted frozen E1 results and E2 ranking-robustness records. It does not fit an estimator or calculate new intervals.
